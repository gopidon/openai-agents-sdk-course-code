# Getting Your OpenAI API Key and Setting Up Billing

*A step-by-step companion guide for Lecture 1.5 — Environment Setup*

> 📌 **Before you start:** OpenAI occasionally redesigns its platform website. The exact button labels or page layout described below may shift slightly over time, but the underlying steps and order will remain the same. If something looks different on your screen, look for the closest equivalent option.

---

## Part 1 — Create Your Account and Generate an API Key

This part gets you a working API key. It takes about two minutes if you already have an account, or five if you are starting from scratch.

### Step 1 — Sign in to the OpenAI Platform

Go to [platform.openai.com](https://platform.openai.com) and sign in, or create a new account if you do not already have one.

> ⚠️ **Important:** the OpenAI developer platform (`platform.openai.com`) is a separate login from ChatGPT (`chat.openai.com` or `chatgpt.com`), even though both use the same underlying account system. If you already use ChatGPT, you can usually sign in with the same email — but you still need to visit the platform site specifically to reach the API tools used in this course.

### Step 2 — Navigate to the API Keys Section

1. Once signed in, look for a section labelled **"API keys"** in the left-hand navigation menu or under your account/organization settings.
2. Click into the API keys page. If this is a new account, the list will be empty.

### Step 3 — Create a New Secret Key

1. Click the button to create a new secret key (often labelled **"Create new secret key"**).
2. Give the key a name you will recognize later — for example, the name of this course, such as `OpenAI Agents SDK Course`.
3. Confirm creation. The full key will be displayed exactly once.

> 🔑 **Critical:** copy the key immediately and store it somewhere safe before closing or navigating away from this screen. OpenAI shows you the complete key only once, at the moment of creation. If you lose it, you cannot retrieve it again — you will need to create a brand new key instead.

### Step 4 — Store the Key Safely (For Now)

Paste the key into a temporary, private location — a password manager, a secure note, or a plain text file you will delete shortly. Do not paste it into any public place: not a chat message, not a public code repository, not a shared document.

> In the next part of Lecture 1.5, you will add this key to Google Colab Secrets, which is the secure, permanent home for it throughout this course. You will not need to paste it directly into any notebook cell.

## Part 2 — Set Up Billing

This part is just as important as Part 1, and it is the step most commonly missed. The OpenAI API runs on a **prepaid billing system**, which works differently from a ChatGPT subscription. Completing Part 1 alone is not enough — without completing this part, your first API call will fail with a billing error.

### Step 5 — Add a Payment Method

1. Navigate to the **Billing** section of your account settings.
2. Click **"Add payment method"** and enter your card details.

> ⚠️ This step alone does **NOT** give you any usable balance. Adding a card on file is only half of what is required — see Step 6 below.

### Step 6 — Add Credit to Your Balance

The OpenAI API is a prepaid system: there is no pay-after-the-fact invoicing for individual developer accounts. You must purchase credit before making any API calls.

1. Still within the Billing section, find the option to **"Add to credit balance"** (sometimes shown as "Add credits" or similar wording).
2. Enter an amount and confirm the purchase. The minimum purchase is typically around $5.
3. For this entire course, a small amount is more than sufficient — the notebooks are designed to use minimal tokens per run.

### Step 7 (Optional) — Set a Spending Limit or Auto-Recharge

These steps are optional but worth knowing about, especially if you plan to keep using your API key beyond this course.

- **Spending limit:** sets a hard cap on total monthly spend, so you never get an unexpectedly large bill.
- **Auto-recharge:** automatically tops up your balance when it drops below a threshold you choose, so a long-running script does not stop mid-way through because your balance hit zero.

Both options live in the same Billing section. Neither is required to complete this course.

## Part 3 — Common Issues and How to Read Them

| What you see | What it means |
|---|---|
| `"Incorrect API key provided"` | The key was copied incorrectly, has extra spaces, or has been deleted from your OpenAI account. Generate a new key and try again. |
| `"You exceeded your current quota"` / billing error | Your credit balance is at zero, or you completed Step 5 but skipped Step 6. Return to Billing and add credit. |
| You cannot find the API keys page | You may be signed into the ChatGPT consumer app rather than the developer platform. Confirm you are on `platform.openai.com`, not `chatgpt.com`. |
| The key was only shown once and you lost it | This is expected behaviour, not a bug. Simply create a new secret key following Step 3 again; the old one can be safely deleted from your key list. |
